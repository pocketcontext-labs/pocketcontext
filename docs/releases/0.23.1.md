# PocketContext 0.23.1

Fixes a crash in the remote MCP adapter introduced in 0.23.0. Bodyless knowledge
requests, including the `schema` tool, could panic during request cleanup and
terminate the entire server. The adapter now supplies an empty request body before
calling the embedded API router directly.

A regression test exercises the direct PocketBase router path. The previous
HTTP-proxied integration fixture normalized empty bodies and missed this failure.

Upgrade MCP-enabled servers to this patch using the normal stop, complete backup,
binary replacement and restart procedure. Preserve the existing service arguments,
OAuth grants, certificate cache and private tunnel identity. Database format remains
1; supported projects from 0.11.x through 0.23.0 require no data conversion.

The embedded manual and generated client prompt are pinned to 0.23.1. Previously
released website prompts remain unchanged.

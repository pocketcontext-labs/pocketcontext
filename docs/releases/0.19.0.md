# 0.19.0 — Agent chat in the reader

Optional built-in chat connects the PocketContext reader to a host-side Codex ACP
adapter. A phone can ask questions and review agent permission requests through the
same signed-in reader. PocketContext still ships its server, reader, CLI, HTTPS and
ACP bridge in one binary; chat additionally needs a separately installed adapter,
Node.js and provider sign-in on the host. No agent runtime is installed on the phone.

- Enable chat explicitly with `serve --chat-agent ABS_EXECUTABLE` and optional
  `--chat-args JSON_ARRAY`. It composes with `--headless`, `--domain` and `--tunnel`.
  Browser requests cannot select an executable.
- The first supported adapter is `@agentclientprotocol/codex-acp@2.5.0` with
  `@openai/codex@0.165.0`. Sessions use read-only mode and on-request approvals.
  Permission controls preserve the adapter's actual choices.
- Host sessions survive browser disconnection. Private local transcripts survive
  server restarts; agent restoration depends on ACP `session/load` support and
  successful restoration. Interrupted work is explicit and prompts are not replayed.
- Knowledge operations use the authenticated CLI/API under generated instructions;
  a scratch directory and instructions do not constitute a security sandbox.
- Chat is disabled unless configured. Existing local reader, native HTTPS,
  private tunnel and external-agent workflows remain available.

Read [chat setup and limitations](../chat.md). Provider authentication is configured
on the host, separately from reader sign-in. External AI services receive the
context the agent sends and their costs and limits apply.

There is no knowledge schema migration. Projects from 0.11.x–0.18.0 keep database
format 1; 0.10.0 and earlier remain unsupported. Follow the [upgrade procedure](../upgrades.md):
verify the release, cleanly stop the project, back up the complete project and
matching old binary, explicitly replace it, then refresh profiles/skills and clients.
Chat transcripts and provider credentials are private machine state, outside the
synced project backup.

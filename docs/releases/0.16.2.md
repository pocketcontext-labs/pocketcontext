# PocketContext 0.16.2

Start an initialized project's headless server and private tunnel with one command:

```sh
./pocketcontext tunnel serve
```

- A stopped server starts headlessly in the background; a compatible running
  server is reused without changing its listeners.
- The tunnel stays in the foreground. Ctrl+C or a tunnel failure leaves the
  database server running. Use `pocketcontext stop` to flush and stop it.
- Missing databases still require explicit initialization. Existing lease,
  conflict, release compatibility and authentication checks remain in force.
- Startup can be interrupted without continuing to tunnel identity setup.
  A background server already launched remains running.
- Generate the client setup prompt separately with `tunnel invite` after the
  tunnel reports readiness. Reader setup and sign-in recovery are unchanged.

No database format, authentication protocol or dependency changes. Existing
single-user databases from 0.11.x through 0.16.1 require no data conversion.
Follow [the upgrade procedure](../upgrades.md), use matching server/client
releases and regenerate installed skills. Earlier website prompt files retain
their original bytes and release pins.

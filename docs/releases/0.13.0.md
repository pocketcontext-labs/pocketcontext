# PocketContext 0.13.0

PocketContext now supports named knowledge bases, a private profile registry and a router skill that selects each project's own version-specific skill. Project identity is checked independently of its display name. Existing global skills can be preserved in dedicated profile directories before installing the router.

Local commands use a private socket. Background startup is headless; opening the reader activates loopback TCP. Explicit TCP mode remains available. Authentication, project leases, snapshot write-back and conflict recovery remain in force.

`tunnel invite --out FILE` creates a private invitation after the supervised tunnel starts. Transfer that file privately and run `tunnel join --file FILE` on the client to forward, verify the project and redeem its one-time code. The client saves the connection for restarts. The invitation's code expires, but its tunnel address remains sensitive until rotated. Neither command prints its secrets.

`manual --out DIR` exports this release's embedded user documentation and a hash manifest without starting a server. Import it into a separate space if desired; identical files deduplicate within that space.

Databases from 0.11.x and 0.12.x remain supported. Databases from 0.10.0 and earlier are refused. Older binaries may discard the project name when rewriting configuration and can replace the global router with their older skill; regenerate the router with this release after using an older skill installer.

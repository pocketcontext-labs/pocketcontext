# PocketContext 0.12.1

Released October 30, 2026.

- The embedded PocketBase is upgraded from v0.40.4 to v0.41.1. PocketBase moved
  its Go modules from `github.com/pocketbase` to `ganigeorgiev.com/pocketbase`;
  PocketContext follows the new paths. Its JS hook and migration APIs are
  unchanged. The upgrade also brings PocketBase's updated dependencies, including
  `golang.org/x/net` security fixes and SQLite (`modernc.org/sqlite` 1.60.1) and
  goja updates.
- Release binaries are built with Go 1.27.3, which PocketBase recommends for its
  security fixes (previously Go 1.27.1).
- The vendored server code otherwise remains unchanged (see
  `internal/pocketcontext/VENDORED.md`).

There are no other changes to the binary, schema, commands, reader or tunnel.
The tunnel still uses tailcat 0.7.0, so existing tunnel addresses keep working.

## Upgrading

Stop the running server and replace the executable of each 0.12.0 project,
ideally by installing 0.12.1 into the project folder. Projects created by 0.11.x
and 0.12.0 open unchanged, with no data migration; databases from 0.10.0 and
earlier remain unsupported (see [0.11.0](0.11.0.md)).

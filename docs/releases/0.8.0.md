# PocketContext 0.8.0

Released October 22, 2026.

- A redesigned light-mode reader separates Overview, All pages and Sources, with responsive navigation, version selection and contextual search.
- Topics and custom catalogs come from published page properties, with optional definition pages for labels, ordering and columns. Navigation follows the selected publication. Empty spaces start without sample catalogs or guides.
- Sources has a searchable directory with 50 rows per page, sorting and direct page navigation. Markdown originals share the reading style of pages; citations show formatted evidence and link to highlighted passages in the original.
- New projects start in Personal. Existing projects retain Company as their default. Manage spaces creates private named spaces and gives owners rename, archive and restore controls. Archiving keeps authorized evidence readable and blocks edits until restored; Company and Personal cannot be archived.
- Reader development supports Vite hot reload through the existing server origin using `serve --ui-dev` and `make dev DB=...`, without rebuilding the executable for UI edits.
- Fixed redundant dividers, a missing source-sort value that produced invalid SQL, and a Windows test fixture that kept a SQLite file open during replacement.

## Upgrading

Stop the running server cleanly and back up the complete project (`pocketcontext.db`, `storage/`, and `pocketcontext.json`) before replacing the executable. Open the same project with 0.8.0; migrations preserve existing spaces, sources, revisions and publications. Keep only one writer for the project.

This remains a text-only local product with authenticated clients. Membership changes are operator-managed; archive is reversible and does not delete evidence.

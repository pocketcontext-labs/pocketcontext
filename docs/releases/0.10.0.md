# PocketContext 0.10.0

Released October 29, 2026.

- `ingest` stores any file, not only UTF-8 text. PDFs, images, audio, office documents and other files up to 50 MiB are kept as immutable originals with a media type taken from their extension, and are reported as `stored` without passages. UTF-8 text is split into passages as before, now also for `.srt` and `.org` files.
- The binary still never parses PDFs, images or audio and calls no external tool or service for them. The user's agent converts them instead: `pending` lists sources with no passages, `original SOURCE --out FILE` downloads a verified original, and `extract SOURCE --text FILE --tool TOOL` records the agent's UTF-8 text or Markdown as an `agent-text` rendition. Its notes record the tool, the hash of the converted text and, with `--original-sha256` and `--conversion`, how the file was shrunk before ingest (for example audio to Opus). Originals are never replaced.
- Agent-text passages are derived evidence, not an exact copy of the original. `passages` reads them and marks them as derived. The reader lists sources without passages under Needs extraction, shows a non-text original's media type, size and download instead of a text preview, and labels its passages, evidence excerpts and search results "Agent-derived text — not an exact copy". View in source does not highlight them in the original.
- A `repository_document` with `output_mode: exact_copy` must name a text source; an agent-text source is refused.
- The skill describes the conversion workflow: shrink the file if needed, ingest, `pending`, `original`, convert, `extract`, then write cited pages. Ingestion of a non-text file is not complete until `extract` has succeeded.

## Upgrading

Stop the running server cleanly and back up the complete project (`pocketcontext.db`, `storage/` and `pocketcontext.json`) before replacing the executable. There are no schema changes for existing projects; existing sources, renditions and citations stay valid, and the tunnel address from 0.9.x keeps working. Run `pocketcontext skill` again to install the updated skill.

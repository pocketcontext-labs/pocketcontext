# PocketContext 0.22.0

PocketContext removes built-in reader chat and the ACP host integration. The
reader focuses on browsing and searching cited knowledge; external agents keep
using the authenticated CLI/API and installed PocketContext skills for questions,
ingestion and synthesis.

- Removed the chat UI, conversation controls, model and permission selection,
  image prompts and dictation, ACP processes and browser chat endpoints.
- Removed `serve --chat-agent` and `--chat-args`. These are now unknown options.
- HTTPS phone access, private tunnels, sources, pages and publication history remain.
- Existing machine-local chat files are left untouched, but are no longer
  accessible through the reader. No transcript export, conversion, compatibility
  layer or automatic knowledge ingestion is provided.
- Knowledge database format remains 1; no knowledge-data conversion is needed.

Current setup prompts, the embedded manual and client invitations are pinned to
0.22.0. Previous release notes describe their historical features.

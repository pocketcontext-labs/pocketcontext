# PocketContext 0.9.2

Released October 25, 2026.

- `ingest` works on Windows again. The source integrity check hashed each original with the external `sha256sum` command, which stock Windows does not have, so every upload failed with "Cannot hash original". Originals are now hashed inside the executable. The digests are identical, so hashes stored by earlier versions keep verifying.
- New projects create only the initial account's private Personal space, owned by that account, and no Company space. Later accounts receive their own Personal spaces. Existing projects keep their saved default and their Company space and memberships.
- Opening a published-page search result in the reader scrolls to and highlights the matching paragraph, keeping the selected space and publication.

## Upgrading

Stop the running server cleanly and back up the complete project (`pocketcontext.db`, `storage/` and `pocketcontext.json`) before replacing the executable. There are no schema changes for existing projects, and the tunnel address from 0.9.0 and 0.9.1 keeps working.

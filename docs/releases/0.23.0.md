# PocketContext 0.23.0

PocketContext adds an opt-in remote MCP endpoint for external assistants on its
native HTTPS domain. Configure one service with
`serve --headless --domain HOST --mcp`, then connect the assistant to
`https://HOST/mcp`. See [MCP setup](../mcp.md).

- Built-in OAuth discovery, automatic client registration, S256 PKCE, explicit
  browser consent, access/refresh tokens and revocation.
- Existing reader sign-in links bootstrap consent without revealing or resetting
  the randomly generated setup password.
- Knowledge and space tools reuse authenticated API rules, including immutable
  evidence, citation checks, revision conflicts and atomic publication.
- File content is bounded and supplied explicitly; non-text conversion remains
  agent-owned. No arbitrary host paths, shell, network fetching or administration
  tools are exposed.
- OAuth state remains machine-local. Knowledge database format remains 1;
  projects from 0.11.x through 0.22.x need no knowledge-data conversion.
- The embedded manual and generated client setup prompt are pinned to 0.23.0.
  Previously released website prompts remain unchanged.

Gemini account linking and actual mobile behavior require user confirmation.
Automated checks are not evidence of voice support or phone attachment transfer.

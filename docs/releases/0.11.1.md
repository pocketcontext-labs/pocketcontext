# PocketContext 0.11.1

Released October 29, 2026.

- The recommended layout now keeps the binary in the project folder, beside `pocketcontext.db`. The project then carries the release that can open it: a release may refuse databases created by earlier ones, as 0.11.0 does, so one shared binary cannot serve projects from different releases. Commands also find the database without `--db`. The README describes two caveats: the installer replaces an existing `pocketcontext` in the folder, so check its version first, and Linux and macOS binaries share a name, so a synced folder used from both keeps the binary elsewhere.
- The installers no longer have a default folder. `install.sh DIRECTORY` (or `POCKETCONTEXT_INSTALL_DIR`) and `install.ps1` with `POCKETCONTEXT_INSTALL_DIR` must name it, usually the project folder; without one they stop before downloading anything.
- The setup prompts on www.pocketcontext.com for this release install the binary into the project folder.

There are no changes to the binary, schema or commands.

## Upgrading

Replace the executable of each 0.11.0 project with 0.11.1, ideally by installing it into the project folder. Projects from 0.10.0 and earlier still cannot be opened (see [0.11.0](0.11.0.md)). Run `pocketcontext skill` again so the installed skill names the new binary path.

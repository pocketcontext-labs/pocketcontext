# PocketContext 0.21.1

Reader chat now has a compact, keyboard-accessible reasoning-effort slider followed by a model menu. Only combinations advertised by the adapter are offered. The selected pair stays visible, and Reset restores the model and effort selected by the adapter when the conversation was created. Existing conversations without a recorded original default keep Reset disabled rather than guessing.

All three native chat permission choices—Read-only, Workspace access and Full access (YOLO)—are available without host environment flags. The initial default remains read-only; read-only/workspace choices are remembered for new chats in the same browser. Full access applies only when explicitly selected for the current conversation and never becomes the new-chat default. During a running turn, increasing to Full access is supported; stop the turn before reducing access.

The reader also includes the workspace-navigation and import-approval-summary improvements made after 0.20.0. Long space names wrap within the space list on desktop and mobile. Local development has a pinned Nix/devenv toolchain and a documented hot-reload workflow. See [development](../development.md) and [chat setup](../chat.md).

The supported reader adapter remains the pinned Codex ACP adapter. Antigravity ACP was assessed but is not yet a supported backend. Fast mode is advertised by the Codex adapter for eligible models, but PocketContext does not yet bridge its session configuration controls.

Headless startup now rechecks the private socket if it appears during a TCP fallback check, avoiding an intermittent false port-conflict error when another program uses the configured reader port. The 0.21.0 tag did not produce a published release; 0.21.1 includes the corrected startup behavior.

There is no database-format change. Projects from 0.11.x through 0.20.0 remain compatible; follow the normal [upgrade procedure](../upgrades.md), including a clean stop and complete backup before replacing the executable. Chat transcripts stay in the host's private cache.

# PocketContext 0.14.0

Connect another computer with one copyable prompt. `tunnel invite` prints a complete client setup prompt containing release-pinned installation instructions and the invitation. Paste it into the other computer's agent; there is no separate invitation file or code to transfer.

- `tunnel join --stdin` reads the invitation, verifies the project identity, signs in and saves a managed background forward. It opens the reader signed in; `--no-browser` returns a clickable single-use link when automatic opening is unavailable. File invitations and foreground forwarding remain available.
- `open --url URL` uses the client's existing authenticated session to obtain a two-minute, single-use browser sign-in link. It no longer requires a separate password login in the reader.
- `tunnel forward --url URL --background` reconnects using the saved address. The server computer and its tunnel must remain running.
- Invitations, one-time codes and reader sign-in links are explicitly supported in the user's setup chats. Passwords, session tokens and private identity keys remain private. An invitation is still an access credential: its single-use code lasts ten minutes and its address retains connectivity until rotation. Intended chat sharing does not require rotation.

No database migration or account change. Stop an existing server cleanly before replacing its binary, restart it with this release and regenerate its skills. Update both server and client to use the new reader sign-in flow. Previously released setup prompts remain available unchanged.

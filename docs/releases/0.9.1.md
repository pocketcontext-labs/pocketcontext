# PocketContext 0.9.1

Released October 22, 2026.

- A running `tunnel forward` now reconnects on its own after `tunnel serve` restarts on the agent computer with the same address. Previously the forward had to be restarted. The first new connection gets through within seconds; connections that were open during the restart end with it. Sign-in is unaffected.

There are no other changes.

## Upgrading

Replace the executable on the person's computer (the forward) and, for consistency, on the agent computer. There are no schema or address changes: the tunnel address from 0.9.0 keeps working.
